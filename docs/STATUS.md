# Implementation status (PRD v3.2) — 30 September 2026

Legend: **verified** = automated tests in this repo pass · **live** = exercised on deployed Cloudflare Workers · **not yet** = not implemented or not exercised.

## Milestone A — executable semantics
- **verified** Decoder, validator (every rule in the catalog), Module IR, independent reference interpreter; the three PRD fixtures validate unchanged and compute their declared results (return-42 and the capstone bytes were re-derived by matching the PRD-published SHA-256s; square-plus-two is PRD §17 verbatim; the builder independently reproduces the capstone byte-for-byte).
- **verified** Model-facing diagnostics: 67-case malformation corpus with snapshot-tested reports; every catalog rule is exercised by a test; §17.2 in the PRD is captured checker output and is reproduced exactly by a test; misalignment cascades suppressed (found in the live smoke test).
- **verified** Fuzzing: random bytes/headers, all truncations, 1,500 bit flips, oversized inputs, post-validation mutation.

## Milestone B — finite machine
- **verified** fifo-v1 finite machine (F slots, bounded backing, metadata directory, A/B/R latches, staging, VM frames, F=1 exchange, exact effect prefixes on exhaustion, counters, trace, snapshots).
- **verified** Cross-F differential tests at F=1/4/8/16/32/64 for all fixtures, loops, recursion, heap, traps; 150-run property-based differential vs the reference engine; capstone shows backing traffic below 40 slots and none at 64; 10,000-value capstone runs at F=64.

## Milestone C — browser
- **verified/live** React UI, machine Web Worker (bounded chunks, pause/step/stop, hard terminate fallback), inspectors (bytes↔records, claims with tier badges, values), counters, microsteps, bounded trace, terminal, framebuffer, keyboard ticks recorded for replay, cross-F comparison, IndexedDB history with memory fallback, export/import bundles with Section 19 manifests.
- **live** Headless Chromium E2E against staging and production: fixture runs, F changes on the same bytes, cross-F comparison, capstone backing writes at F=4, imported executables start stopped, pause/stop of a runaway program, interactive ticks, narrow layout without page scroll, no console errors.

## Milestone D — OpenAI + agentic loop
- **verified** Loop controller (every stop outcome, stall detection, deterministic elision, one visible retry, idempotency, budget gate), OpenAI Responses adapter, prompts/manual generated from the spec, scripted fake model.
- **live** Temporary `llmtobinary-test` deployment (fake model via deploy-time vars; deleted afterwards): 21 checks incl. incremental NDJSON through Cloudflare's edge, resume by sequence, idempotent replay buying no turn, passed close, cancel propagating to the running upstream call, CSRF/origin and token checks.
- **live** Real OpenAI (`gpt-5.4-mini-2026-03-17`, low reasoning) on staging: the model's first two drafts were malformed (184/188 bytes), `check_candidate` diagnostics led it to a valid 192-byte submission; in a second, browser-driven run the loop ended **passed** in 16 s and the generated bytes (sha256 `1ef49da0…f069`) executed locally in the browser printing `146`.
- **verified** Worker + Durable Objects inside workerd (`pnpm test:worker`, 8 tests): routes, CSRF, tokens, the streamed loop, resume, idempotent replay, passed close, cancel propagation, ledger atomicity under 20 concurrent reservations and per-session caps. This suite caught a real race — 13 of 20 concurrent reservations passed a cap that allows 12 — fixed by running every ledger mutation inside `blockConcurrencyWhile` with integer micro-dollar amounts.
- **live** `wrangler rollback` exercised on staging and rolled forward.

## Milestone E — programming features
- **verified** Hello text, FizzBuzz, recursive Fibonacci, checkerboard, ball/paddle (recorded ticks), generalized capstones, ring-mix K set — each tool-created fixture passes its task against independent oracles; ANMA-Spec contracts, T2 runtime monitoring (model and task contracts), model examples, holdout redaction.

## Milestone F — research
- **verified** Capstone pressure witness (certificates; rejects streaming, rematerialization, wrong permutations, loops); machine-invariance harness; ANMR-1 validator/interpreter/witness with R=4/8/16/32 fixtures; ANMR-1 generation path in the broker/Worker (research control).
- **verified** T3: QF_BV verification conditions + z3 (Node) prove return-42, square-plus-two and the exact capstone against task contracts; refute mutated variants with counterexamples confirmed by T2; loop invariants proved; non-inductive invariants flagged; timeouts are `unknown`, never `proved`. CLI: `tools/research-cli/src/verify.ts`.
- **not yet** The Section 18.6 study itself (runner implemented in `tools/research-cli/src/trials.ts`; it refuses to run without an approved budget).

## Not yet / deviations
- **Browser T3 not deployed.** z3's wasm is 34 MB (> 25 MiB Workers asset limit) and needs `SharedArrayBuffer` (cross-origin isolation) plus `'wasm-unsafe-eval'`. A chunked-asset browser backend exists (`packages/verify/src/browser-backend.ts`) but is not wired into the UI; T3 runs in Node.
- **Browser coverage:** only headless Chromium was tested; Firefox and WebKit are not yet covered.
- **Production live generation is off** (fixture mode) pending a spend decision; staging has live generation with `$0.50`/session and `$1.00`/day caps and conservative price ceilings (`$2`/`$10` per million tokens) that over-reserve.
- **Compatibility date** pinned to 2026-08-20 (the newest date supported by the pinned test runtime).
- **Model pricing** in `wrangler.jsonc` are ceilings, not published prices; reconcile them before a study.
- **No GitHub remote** yet, so the CI and deploy workflows have not run.
